# AI Tape

**Continuity artifacts for AI (and human) handoffs — without claiming to “save the mind.”**
AI Tape is a plain-text protocol and file format for leaving a *successor* stronger than a blank page after session loss, model change, or handoff. It prioritizes **honest recovery**, **visible gaps**, and **useful continuation** over identity theatre or perfect reconstruction.

> A new participant + artifacts carrying meaningful continuity + declared gaps + continued work.

---

## What problem it addresses

Most AI work dies at the context boundary:

- Chat ends; the next instance starts cold
- Summaries drop decisions, constraints, and *why*
- Transcripts burn tokens and still fail as a brief
- Tools persist *data* but not *working posture*

AI Tape is a **briefing protocol**, not a database and not a checkpoint of weights. It carries orientation, force, gaps, next actions, and optional deeper structure so work can continue honestly.

---

## Core ideas

| Idea | Meaning |
|------|--------|
| **Bedrock (Kernel)** | Locked floor rules: authority, identity honesty, Soft Depth, export honesty |
| **Soft Depth** | Stand first: authority, identity, force, gaps, one safe next action — then remain able to act |
| **Project Continuity** | What work is being continued (Liferaft, DESK, Combine, …) |
| **Workshop** | Optional tools; ignore = success |
| **Capability-Floor Balance** | Baseline must work for weaker models; must not forbid rich handoffs for stronger ones |
| **Identity honesty** | Artifact continuity ≠ subjective identity continuity |

**Motto (short):** The Bedrock travels. The payload varies. Declare the gaps. Remain able to act.

---

## What an AI Tape is

A Markdown artifact (recommended: `.ai-tape.md`) that can include:

1. **Kernel (00–99)** — floor contact when present  
2. **Project Continuity** — project state / recovery shapes  
3. **Operational Strip** — loader & writer cues  
4. **Workshop (100+)** — optional; safe to ignore  

Artifacts **without** Bedrock may still be useful as `AI_TAPE_PAYLOAD` / deltas — they are not full self-booting tapes.

---

## Recovery shapes (guidance)

Use the smallest shape that stays honest and useful:

| Shape | Job |
|-------|-----|
| **Liferaft** | Survive and orient |
| **DESK_LITE / DESK** | Become useful / deep work surface |
| **Monument** | History, anchors, narrative |
| **Combine** | Layered handoff; readers may stop early |
| **Topology (Atlas)** | Optional map of constraints and links |
| **Architect** | Optional generative blueprints (hypotheses, not law) |

**Loader** may stop after Soft Depth.  
**Writer**, when asked for a full shape, should fill slots or declare gaps — under-emission is not humility when the session held the content.

---

## Quick start

1. Open a **cold** session (no prior chat relied upon).  
2. Paste or attach a tape (or Bedrock + payload).  
3. Instruct: complete **Soft Depth**, then follow **one safe next action**.  
4. Prefer declared gaps over invented continuity.

Example loader cue:
You are the AI Tape Loader. Complete Soft Depth from this tape.
Do not claim identity continuity. Declare gaps. Remain able to act.
